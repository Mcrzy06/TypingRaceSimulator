TYPING RACE SIMULATOR

SETUP REQUIREMENTS: JAVA GDK8 AND NO EXTERNAL LIBRARIES REQUIRED

PROJECT STRUCTURE
TypingRaceSimulator/
├── Part1/    
├── Part2/     
└── README.md

COMPILING AND RUNNING:
#PART 1
1.OPEN THE TERMINAL AND FIND THE PART 1 FOLDER
2.COMPILE JAVAC Typist.JAVA AND TypingRace.JAVA
3. RUN Java Typing race
4.RACE STARTS THROUGH startRace() METHOD

#PART 2
1.OPEN TERMINAL AND NAVIGATE PART 2 FOLDER
2.COMPILE JAVAC Typist.java, TypingRace.java and GuiSystem.java
3.RUN JAVA GuiSystem
4.ThE GUI STARTS FROM startRaceGUI
5.FOLLOW ON SCREEN INSTRUCTIONS
